**Sarvkrit lives in the menu bar and fixes the things macOS does differently than you'd expect.** Everything ships switched off; turn on only what you want.

Nineteen features now, up from sixteen — and the menu bar itself is a different thing than it was in 1.0.

## Screenshots

![Sarvkrit's capture bar: Area, Fullscreen, Window, Scrolling, Timer and Text, with Cancel and Capture beside it](https://github.com/sadana-psylief/Sarvkrit/raw/v1.1.0/docs/images/capture.png)

Capture an area, a window, or the whole screen. **The screen freezes while you choose**, so an open menu or a tooltip stays put instead of vanishing the moment you click — and because the selection is drawn over a picture that has already been taken, the magnifier and the live pixel readout cost nothing.

A window capture is taken on its own rather than cut out of the screen, so its shadow can be kept or dropped and its corners can be genuinely transparent instead of showing whatever was behind it.

**Scrolling capture** takes a frame each time you pause while scrolling and stitches them into one tall image. It watches your scrolling rather than doing the scrolling for you, which is why it needs no extra permission.

**Text recognition** reads the text — or a QR code — out of any part of the screen and puts it on the clipboard. It runs on your Mac, and a scanned QR payload is copied rather than opened, because following a link scanned off the screen should be your decision.

**Pin to Screen** floats a shot above everything else while you work. Lock Mode makes it ignore clicks so you can work through it; **⌃⇧P** unlocks every pinned shot. And **⌃⇧⎋ always clears the screen** — overlays, pinned shots, the capture bar, whatever state any of it is in.

### The editor

![The annotation editor's toolbar — Select, Crop, Arrow, Line, Rectangle, Ellipse, Text, Counter, Emoji, Pencil, Highlighter, Blur, Pixelate and Spotlight — above a finished screenshot with a bowed arrow, a highlighted region and a numbered counter on a mesh-gradient background](https://github.com/sadana-psylief/Sarvkrit/raw/v1.1.0/docs/images/editor.png)

Arrows, shapes, text, counters, a highlighter that snaps to lines of text, and backgrounds you can change.

**On blurring things out.** An ordinary blur is reversible — blurred small text is routinely recovered — and so is pixelation when the alphabet is small, which is exactly the password case. So Sarvkrit names them for what they are and offers a **secure** mode that keeps nothing but the average colour of the region, with texture generated from a seed rather than from your pixels. A weak blur over a password is worse than none, because you'd share it believing it was hidden.

### Scriptable

Every capture mode has a `sarvkrit://` URL, so Raycast, Alfred, Shortcuts, a Stream Deck key or a shell script can drive it. Names follow the ones scripts are already written against, so switching an existing `cleanshot://capture-area` script over needs only the scheme changed.

## A dashboard in the menu bar

![Sarvkrit's menu bar panel showing the System tab: CPU, GPU and battery temperatures as tiles, then live CPU, GPU and memory readings with sparklines and an uptime line](https://github.com/sadana-psylief/Sarvkrit/raw/v1.1.0/docs/images/dashboard.png)

The dropdown used to be a switchboard: a tab per feature category, holding that category's switches. It leads with what the features actually *show* now — System, Network, Disks and Power, each with live readings and two minutes of history. The switches are all still there, in the Features tab.

**Displays** is new with it: the brightness of every connected screen, including externals, which the brightness keys don't reach. Where macOS can set the real backlight it does; everywhere else it dims the picture and the panel says so, rather than offering a slider whose top half does nothing.

## It can tell you about the next release

1.0 had no way to say a release had happened, which is most of why this one is as big as it is.

Sarvkrit now ships a launchd job — eighty lines of shell you can read at `Sarvkrit.app/Contents/Resources/check-for-update.sh` — that asks GitHub once a day what the newest release is. An unauthenticated `GET` with no token, no query string and no identifier of any kind. It never installs anything: when a newer version exists the menu bar says so and Settings shows you the command.

It is a separate job rather than code inside the app so that you can switch it off and lose nothing else. It appears in **System Settings → General → Login Items**, and in **Settings → General**. With it off, Sarvkrit makes no network requests whatsoever.

## Two things 1.0's notes said that are no longer true

They said Sarvkrit has no network code at all, and that it asks for no screen-recording permission. Both were true then and neither is now:

- **The update check reaches the internet**, as described above. Nothing about you or your Mac is sent, it is off by one switch, and it is the only request Sarvkrit makes.
- **Screenshots needs Screen Recording.** macOS classes reading what's on your display as recording the screen. Unlike Accessibility, macOS does not hand this grant to an app that is already running — after you allow it Sarvkrit has to restart before it can capture anything, and it offers to do that rather than leaving you with black rectangles. Pin to Screen needs nothing at all.

Nothing else changed. There is still no camera or microphone permission; Privacy Guard asks the system whether the camera is on, which is a question about the device, and never opens it.

## Install

1. Download `Sarvkrit.dmg` below and drag **Sarvkrit** to your Applications folder. Put it there rather than leaving it in Downloads — macOS keys permissions to where the app lives.
2. **First launch: System Settings → Privacy & Security → Open Anyway.** Only the first time.

   Double-click Sarvkrit, click **Done** on the warning, then open **System Settings → Privacy & Security**, scroll down to **Security**, and click **Open Anyway** next to Sarvkrit. Authenticate, open Sarvkrit again and choose **Open**. From then on it opens normally.

   That second step is not optional, and it is not a warning you can ignore: this build is signed but **not notarized**, because notarization needs a paid Apple Developer account. Double-clicking alone will get you "Apple could not verify Sarvkrit is free of malware" and nothing else.

   Not *right-click → Open*: macOS 15 Sequoia removed that override, so on 15 and later it shows the same refusal with no Open button. Open Anyway works on 14 too, so it is the only route given here. If you would rather use a terminal, `xattr -dr com.apple.quarantine /Applications/Sarvkrit.app` does the same thing.

Or skip the whole detour with one command:

```
curl -fsSL https://sarvkrit.com/install | sh
```

That works because macOS quarantines what a *browser* downloaded and curl sets no such attribute, so Gatekeeper's first-launch check never runs. Which is why the script does the equivalent check itself — signature intact, signed by this team — and installs nothing if either fails.

## Upgrading from 1.0

Drag the new copy over the old one, or run the install command above. Your settings, clipboard history, snippets and shelf are all kept.

Everything in **Capture** is off, like every other feature — 1.0's settings are respected, and nothing switches itself on.

## Requirements

- **macOS 14.4 or later.** Core Audio process taps are the only public way to do per-app volume and they don't exist before 14.4; everything else here would run on 14.0.
- **Universal** — Apple Silicon and Intel (`x86_64 arm64`).

## What's in it

Nineteen independent toggles across seven groups:

- **Keyboard** — Finder Cut & Paste (⌘X then ⌘V), Text Snippets
- **Clipboard** — Clipboard History (⌘⇧C)
- **Windows** — Window Management (⌃⌥ + arrows), Quit on Close
- **Capture** — Screenshots (⌃⇧A), Pin to Screen (⌃⇧P)
- **Files** — File Rules, Trash Cleanup, App Sweep, Shelf (⌃⌥S)
- **Sound** — Audio Devices (⌃⌥O), Mute Microphone (⌃⌥M), Music Blocker, Volume Mixer, Privacy Guard
- **System** — Displays, Keep Awake, System Monitor

## Verifying the download

```
shasum -a 256 Sarvkrit.dmg
@SHA@
```

The app inside is signed and passes `codesign --verify --strict`.
